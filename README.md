# kikicom

**自分の場所に1台、安価な受信機を置いたら、頭上に何が飛んでいるかがわかる。**

ADS-B(1090MHz、航空機の位置・高度・速度等のブロードキャスト)をRTL-SDR 1台で受信し、地理空間情報として可視化する研究プロジェクト。目指しているのは「札幌の空の記録」そのものではなく、**どこに置いても使える、受信・蓄積・解析の手法**。札幌・新千歳空港周辺は、その手法を具体化するための最初の実例にすぎない。

[dwg7/kikimimi](https://github.com/dwg7/kikimimi)(公共ラジオを社会センサーとして使うプロジェクト)と同じRPi 4B + RTL-SDRのハードウェア一式を時分割で共有する、姉妹プロジェクト。「安価な受信機で、ありふれた放送を社会センサーに変える」という同じ発想を、音声(NHK-FM)ではなく構造化テレメトリ(ADS-B)で追っている。ミッション・データの性質・法的な扱いは全く別。

## これは何か

ADS-Bは、航空機が自機の位置・高度・速度等を、特定の相手方を想定せずブロードキャストし続ける仕組み。FlightRadar24・FlightAware・ADS-B Exchangeといった世界規模のクラウドソース受信網が、まさにこの性質を前提に、個人の安価な受信機からのデータ提供で成立している。

## 手法:場所を選ばない部分

- **受信環境の定点観測**:公開受信網(adsb.lol)と突き合わせ、自分の受信機がどの方位・仰角をどれだけ捉えられているか(=アンテナの「窓の視界」)を継続的に測る
- **要確認一覧**:受信した機体を毎時自動で分類し、公用機・自衛隊機の候補、一般航空、緊急スコーク(7500/7600/7700)などを拾い上げる
- **生の1通を手で読む学習ノート**:CRC・CPR位置符号化・Mode Sの仕組みを、実際に受信したフレームで一つずつ確かめる

どれも、受信点をどこに置き換えても同じように動く。中身(何が見えるか)だけが土地ごとに変わる。

## 実例:札幌・新千歳空港周辺(2026年9月〜)

月寒(札幌市豊平区)から見えているのは、性質の異なる3つの層が重なった空だった——**新千歳(国内屈指の高頻度路線を持つ主要空港)の発着**、**丘珠(近距離の小空港、全方位で拾える)の地域路線**、そして**カムチャツカ・北極圏方面へ抜ける国際便が、たまたま同じ南の窓を高高度で通過していく背景交通**。空港の近くに住む人なら、形は違えど同じような重なりに出会うはずだ。
